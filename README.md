Руководство пользователя по игре "найди скрытую пару"!
Данная игра создана для развлечения пользователей и улучшения памяти. Подходит для категории людей +3 лет! При запуске игры высвечивается сетка размером 4 на 4,в которой скрыты пары одинаковых значков.
При нажатии на одну из клетку показывается некоторый значок,который исчезает через время.Методом перебора и с помощью запоминания нужно найти все пары значков.
Цель игры заключается в том ,чтобы каждому значку найти свою пару.
